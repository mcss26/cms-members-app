# Midnight Club - Brand & UI Guidelines

## 1. Color Palette (Zinc System + Gold)
- **Backgrounds:** Puro negro (`#000000`) para el fondo base (body), gris ultra-oscuro (`#0a0a0a` y `#0c0c0c`) para superficies y tarjetas.
- **Brand Gold:** `#e4d2a8` (Oro principal para títulos, bordes y acentos de marca) / `#c9a96e` (Hover/Dark Gold).
- **Text:** Blanco puro (`#ffffff`) para texto primario, gris medio (`#a1a1aa`, `#9b968d` o `#888888`) para texto secundario.
- **Accents:** Blanco para botones primarios. Verde vibrante (`#4ade80`) exclusivamente para destacar passwords o estados de éxito.

## 2. Tipografía y Estructura (Swiss Brutalism)
- **Sans-Serif:** `Inter`, `-apple-system`. Uso: Párrafos, headers y UI general.
- **Monospace:** `JetBrains Mono` o `monospace`. Uso: IDs de miembros (MC-XXXXX), Contraseñas y metadatos técnicos.
- **Jerarquía y Estilo:** Títulos en caja alta (uppercase) con *tracking* amplio (letter-spacing: 2px o 3px) para enfatizar lujo y exclusividad. Cero bordes redondeados excesivos (usar 4px a 8px máximo). 

## 3. Tono de Voz (Copywriting)
- **Personalidad:** Sofisticado, directo, exclusivo, sutilmente crudo y sin rodeos.
- **Lenguaje:** Español de Argentina (voseo: "Ya sos parte", "Ingresá", "Usá").
- **Regla de Oro:** Menos es más. Evitar párrafos largos de marketing. Mensajes transaccionales precisos y formales pero con actitud moderna.

## 4. Diseño de Emails (Resend/HTML Templates)
- **Fondo General:** Siempre negro (`#000000` o `#050505`). NUNCA fondos blancos.
- **Estructura Layout:** Contenedor central (max 600px). Header con nombre del club centrado y un divisor sutil de oro (`border-bottom: 1px solid #e4d2a8`).
- **Tarjetas/Bloques de Datos:** Fondo diferenciado muy leve (`#0c0c0c`), bordes finos crudos (`1px solid #1a1a1a`).
- **Datos Críticos:** IDs y Contraseñas deben resaltar drásticamente del resto del layout, usando fuentes más grandes, bold y colores de alto contraste.
